Class: Long

Long(low, high, unsignedopt)

A Long class for representing a 64 bit two's-complement integer value.

Constructor

new Long(low, high, unsignedopt)

Constructs a 64 bit two's-complement integer, given its low and high 32 bit values as *signed* integers. See the from* functions below for more convenient ways of constructing Longs.
Parameters:
Name Type Attributes Description
low number The low (signed) 32 bits of the long
high number The high (signed) 32 bits of the long
unsigned boolean <optional>
 Whether unsigned or not, defaults to signed
